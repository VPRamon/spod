# Lints and Safety

The workspace pins a strict lint and safety policy in the root `Cargo.toml`
under `[workspace.lints]`. Every crate opts in via:

```toml
[lints]
workspace = true
```

This document explains each gate, why it is set, and how it is enforced
in CI.

## Policy table

| Category            | Lint                                  | Level    | Rationale                                                       |
|---------------------|---------------------------------------|----------|-----------------------------------------------------------------|
| `rust`              | `unsafe_code`                         | `forbid` | No FFI surface in this workspace; no `unsafe` is justifiable.   |
| `rust`              | `missing_docs`                        | `deny`   | Every public item must be documented.                           |
| `rust`              | `unreachable_pub`                     | `warn`   | Catches accidental over-exposure of internal items.             |
| `clippy`            | `all`                                 | `deny`   | Zero clippy warnings tolerated in PRs.                          |
| `clippy`            | `todo`                                | `deny`   | No `todo!()` macros in committed code.                          |
| `clippy`            | `unimplemented`                       | `deny`   | No `unimplemented!()` macros either.                            |
| `clippy`            | `dbg_macro`                           | `deny`   | `dbg!()` is a debugging aid, not production code.               |
| `clippy`            | `print_stdout`                        | `warn`   | Library code must use `tracing`; binaries may opt out per-line. |
| `rustdoc`           | `broken_intra_doc_links`              | `deny`   | Documentation must compile cleanly.                             |

## Why `unsafe_code = forbid`

`spod` is a pure-Rust workspace (see
[ADR-0001 — pure Rust only](../adr/0001-pure-rust-only.md)).

- There is **no FFI surface** in this workspace. The closest equivalent
  (`siderust-ffi`) lives in the `siderust` upstream tree, not here.
- All performance-critical primitives (`faer` linear algebra, Chebyshev
  evaluation, SGP4 propagation) are provided by upstream or sibling crates
  that already vet their own `unsafe` usage.
- POD-domain code never needs raw pointers, manual memory management, or
  uninitialised reads.

`forbid` (rather than `deny`) means the lint cannot be locally relaxed
with `#[allow(unsafe_code)]`; any attempt is a compile error.

## Public-API snapshot gate

Each library crate ships a baseline of its public API in
`crates/<crate>/api.snapshot`, generated by [`cargo-public-api`].
The script `scripts/snapshot_public_api.sh` performs a diff between the
committed snapshot and the current API.

- **Today**: advisory. A diff produces a CI warning but does not fail
  the build. Updating the snapshot is part of the PR diff and reviewed
  alongside the change.
- **After 1.0**: gating. Any unintentional API change fails CI and must
  be either reverted or accompanied by a snapshot update plus a SemVer
  justification.

See [ADR-0004 — public API snapshots](../adr/0004-public-api-snapshots.md)
for the full rationale.

## Per-crate `[lints]` requirement

Every member crate of the workspace MUST contain:

```toml
[lints]
workspace = true
```

CI verifies this via a small grep step; a crate that omits the section
is rejected.

## CI gate summary

The CI pipeline runs (in order):

1. `cargo fmt --check` — formatting.
2. `cargo clippy --workspace --all-targets --all-features -- -D warnings` —
   the lint matrix above.
3. `cargo test --workspace --all-targets` — unit + integration tests.
4. `cargo test --workspace --doc` — doctests (every public item carries one,
   see [`../conventions/examples-and-doctests.md`](../conventions/examples-and-doctests.md)).
5. `scripts/snapshot_public_api.sh` — public-API diff (advisory pre-1.0).
6. `cargo deny check` — license / advisory / source policy.

A red light on any of these blocks merge.

[`cargo-public-api`]: https://github.com/cargo-public-api/cargo-public-api
